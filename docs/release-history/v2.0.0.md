# Ordo v2.0.0

QuickContactsWidget becomes Ordo, a modular personal assistant.

Modules:
- Contacts: existing transparent contact widget and call overlay.
- Tasks: add, complete and delete tasks.
- Reminders: choose date/time and alert mode (sound, vibration or silent).
- Upcoming events: create events with optional notes; automatically ordered by time.
- Dashboard: shows open task count and the nearest reminder/event.
- Existing GitHub in-app updater remains available.

The Android applicationId is intentionally unchanged so signed updates continue to work.

- Reminders are restored after phone reboot/app update.
- Ordo requests exact-alarm access when needed so timed reminders can fire precisely.
