# Ordo v2.3.1

- Reminder notifications can open a full-screen Ordo reminder over the lock screen.
- Adds an animated pulse/ring reminder screen.
- Sound reminders use alarm audio usage; vibration and silent modes remain supported.
- Adds a 10-minute Snooze action and a clear Dismiss action.
- Keeps the normal notification as a fallback if Android does not allow full-screen presentation.
- Adds USE_FULL_SCREEN_INTENT and lock-screen activity flags.
- Fixes the AudioAttributes build issue by using supported audio usages.
