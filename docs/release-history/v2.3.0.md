# Ordo v2.3.0

- Reminder alarms continue to use `setExactAndAllowWhileIdle` when exact-alarm access is available, allowing delivery during Doze/screen-off states.
- Reminder notification channels were upgraded to high-importance lock-screen-visible reminder channels.
- If the phone was fully powered off when a reminder/event notification should have fired, Ordo now catches up after boot for missed notifications from the previous 24 hours.
- Delivered notification IDs are remembered to avoid duplicate catch-up notifications.
- The Ordo widget button now checks `AppWidgetManager.getAppWidgetIds()` before requesting a new pinned widget.
- If a widget is already present, Ordo does not request another one and shows a short message instead.
