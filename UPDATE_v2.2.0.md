# Ordo v2.2.0

- The main Ordo widget is now a general app feature and its add/pin button was removed from the Contacts module.
- The Ordo dashboard now contains the general widget control.
- Add-task, add-reminder and add-event dialogs use a custom Ordo card UI instead of stock Android input dialogs.
- Widget quick-add for Tasks and Reminders no longer opens an app page.
- Widget quick-add opens an interactive overlay above the home screen.
- Task quick-add supports typing and saving directly from the launcher.
- Reminder quick-add supports title, date (today by default), time, and sound/vibrate/silent mode directly from the launcher.
- Widget counts/next reminder refresh immediately after quick-add.
- Includes the v2.1 ListRows compile fix.
