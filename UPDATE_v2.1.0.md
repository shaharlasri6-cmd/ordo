# Ordo v2.1.0

- Completely redesigned dark modular UI.
- Home button added to Contacts, Tasks, Reminders and Events.
- Contacts: Demo widget action is compact; overlay-permission and update cards removed.
- Reminders: today is now the default; users normally choose only a time, with an optional other-date flow.
- Events: configurable phone notification lead time from event time up to one day before.
- Main widget: contacts remain on top; quick Task and Reminder cards are added below.
- New Ordo launcher icon resource forces the launcher away from the legacy contacts icon.
